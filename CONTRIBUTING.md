# Contributing

Pull requests against `main` are welcome.

- Keep the educational / authorized-use disclaimer in the README.
- Do not commit cloned tool trees, virtualenvs, scan output, logs, or secrets.
- Test installer changes on Zorin OS or another Ubuntu apt-based system (`bash -n` at minimum; a real install when you can).
- Shell scripts should stay executable (`100755`) with LF line endings.

This repo is the Zorin installer only. Do not send changes here that belong in `osint-wsl-setup`.
